# Image credits

The plates on the [chakras section](web/index.html) of the ChakraView site are
**public-domain works** obtained from [Wikimedia Commons](https://commons.wikimedia.org/).
Each was checked individually: only files whose Commons licence field reads
*Public domain* were used. Nothing here is taken from an image search, a
Pinterest board, or a television adaptation — those are copyrighted, and
bundling them into an MIT-licensed repository would infringe.

The files in `web/assets/img/chakras/` are cropped, resized and duotoned
versions of the originals. The sources span four centuries and three
traditions — Mughal manuscript painting, Pahari painting, and early
twentieth-century book illustration — so a single duotone is applied to all
of them to make the set read as one. The originals are unmodified at the
links below.

## Reuse

Because every source is public domain, the derived files in
`web/assets/img/chakras/` carry no additional restriction and may be reused
freely. Attribution is not legally required for a public-domain work, but it
is recorded here because crediting the artist is the right thing to do and
because it lets anyone re-verify the licensing.

## If you add an image

1. Use Wikimedia Commons, and confirm the licence field reads *Public domain*
   or an explicit free licence. "No known copyright restrictions" is not the
   same thing.
2. Record the file, artist and date in the table above.
3. Keep the derived file under 60 KB — `tools/check_links.py` enforces an
   image-size budget on the pages.
